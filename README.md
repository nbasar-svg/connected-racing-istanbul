# Connected Racing — Istanbul

Static event website, ready for GitHub Pages. No build step is required.

## Publish

Use the authorized GitHub account or organization. In repository Settings → Pages, select Deploy from a branch, main, and / (root). The published project URL is https://OWNER.github.io/REPOSITORY/.

GitHub Pages hosting approval for this Salesforce project has not been verified. Repository access and permission to publish a website are separate.
